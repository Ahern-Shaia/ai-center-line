01產品定位

戰情室是為工廠 GM 每天 09:00 開會前 30 秒掃完六格、出問題才深挖的儀表板產品。日常節奏優先，depth 藏在 drawer 裡。

產品戰情室（LINE 群組 AI 分類 → 每日簽核 → Ragic 匯流）
使用者工廠 GM · 群組負責人 · 顧問 · AIPROOT 內部
情境每天 09:00 掃六格 → 30 秒完成當日簽核 → 出問題時深挖來源
對標Datadog（light）· Grafana（light）· Metabase

02五條核心原則

P1
每個數字要能反查來源
CLAUDE.md R11 落實。儀表、抽取、簽核，每筆背後掛得到原始 LINE 訊息或工單。
P2
一頁掃描 > 多頁跳轉
Daily driver 一頁看完所有部門（N 由客戶自行配置，此處示範 6 個），深挖才用 drawer；不強迫用戶切頁。
P3
色彩帶意義，不做裝飾
emerald / amber / rose = 正常 / 待確認 / 逾時，配燈點與文字，非單靠色。
P4
AI 產出必配信心度
高綠、中黃、低紅框攔截；信心度理由可展開查。誠實低值是加分。
P5
警訊放在資訊旁
「已逾期未派工」直接寫在筆數旁，不只讓部門變黃燈就閃過。

03avoid-list（禁令）

🚫 以下元素於本 profile 一律禁用
  • §01 §02 §03 章節符（期刊/藍圖排版慣例）
  • 四角量測記號 .rc tl/tr/bl/br（藍圖繪圖語彙）
  • 網格背景線（工程圖紙感）
  • Mono 濫用於 label / hint / 按鈕（mono 只用於數字、代碼、ratio、ticket id、路徑、時間戳）
  • 「Client × Vendor」共同 branding（如「台灣福祉 × AIPROOT」）
  • 9–11px 小字（最小 12px；sidebar group label uppercase 11px 為唯一例外）
  • Purple gradient / glow / neon / 深色區塊
  • 純 .catch(()=>undefined) 卡「載入中」（三態必齊：skeleton / error / empty）
  • Footer 塞 as-of / demo 警語（該資訊放頂部）

10燈號 & Pill

燈 = 部門/群組整體健康狀態（一部門一燈）· Pill = 單筆 ticket 的信心度/狀態（一筆一 pill）。

狀態語意 · 靠文字前景色扛（無側邊裝飾）

砍掉燈點、砍掉左色帶。狀態全部搬進狀態文字：「4 筆待簽」中性、「1 筆低信心 · 已攔截」紅字、「已由 建國 09:15 簽核」綠字。低信心行只做整行極淡背景 wash（rgba(warn, .025)），不做 border。

4 筆待簽 — 標準狀態
2 筆待簽 · 1 筆低信心 · 已攔截 — 含低信心
已由 建國 09:15 簽核 — 已完成（行本身仍中性）
今日無待簽 — 群組安靜

Tag（狀態標記）

Outline 硬邊 2px、tabular 對齊、中文優先。訊息量靠內容傳達（高信心 / 中信心 / 低信心 / 攔截 / 已同步 Ragic），不用縮寫代碼。

13動效

唯一 easing · cubic-bezier(.32, .72, 0, 1)（fast-out slow-in）。不做多 easing、不做大位移、不做色相過渡。

Micro 100–150ms · hover / focus
Enter 180–200ms · drawer / toast
Loading spin 600ms linear infinite · 刷新中
Skeleton shim 1400ms infinite
Typing dots 1s infinite · RAG 對話 pending

動效原則

  • 一律靠近 UI 邊緣（drawer 從右滑、toast 從右上進）
  • 移動距離 4–24px，不用大位移
  • 不做迴圈動畫，除非表達 loading
  • 顏色不做過渡（瞬切或 100ms 內完成）
  • 不做 transform 3D、scale > 1.05、filter blur/glow
  • prefers-reduced-motion → 全域 .01ms（保功能不保效果）
