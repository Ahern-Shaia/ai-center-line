1單軸清單，取代多欄格

眼睛一路往下掃，順序明確。不再是「左右上下都要看」的參差卡片格。

現況：3 欄 masonry-like，高度不齊、留白參差、閱讀順序不明
改成：一欄 feed，每群一列、高度一致
2訊號優先：需注意的置頂 + 燈點

「未分派部門 / 分析未完成 / 有新任務」用琥珀燈點與 pill 標出並置頂，掃描時眼睛只在這些地方停。

摘要條「2 群需注意」+「只看需注意」一鍵過濾
3漸進揭露：預設收合

每列預設只給一行摘要（幾則 / 最新一句），點開才看細節。不再一次攤開所有群的全文。

「確認沒漏事」＝掃摘要行；要深入才展開那一群
4無活動的群收成一行

今天沒事的群不各佔一格，收成「另 3 群今日無活動」一行，把版面讓給有事的群。
