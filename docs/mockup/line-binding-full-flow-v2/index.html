💡 設計要點
  • Alice 主線只用 LIFF 路（Stage A→B→C→D） · 全程手機 LINE 內 · 60 秒完成
  • Web 路是選配（Stage E→F） · 大螢幕編輯 / 週報回顧場景才用 · 一鍵 LINE 登入免密碼
  • 「一次綁定 · 兩處識別」 · 一次 Stage B 綁定完 · 之後 LIFF (Stage D) + Web (Stage F) + 群組訊息識別全通
  • Auth 統一走 user_line_binding 表 · lineUserId 是 LINE 服務端簽發 · 不能偽造
  • Alice role = employee · Web sidebar 只有「我的日報」· 不會誤看主管級功能
  • 主管級（tenant_admin / group_owner）走 email + 密碼 · 有 2FA · 可管人事看戰情室
