同一份版型，餵不同資料自動長出來 —— 這頁刻意放 5 部門、其中「技術研發」塞 20 人，證明不會崩。

怎麼不崩的（三招）： ① 座標用「量」不用「排」：節點交給 CSS flow 排（一部門一直欄），連線在 render 後用 getBoundingClientRect 量真實位置再畫 → 任何數量都對得上。 ② 成員溢位收合：每部門最多顯示主管+4 人，其餘收成「＋N 位」node（點擊展開）→ 20 人不會爆。 ③ 部門多就水平捲：一部門一直欄，加部門只是多一欄、不用重算 → 5 個、10 個都排得下。
拉寬/縮小視窗、或點「＋N 位」，連線都會自動重畫。
