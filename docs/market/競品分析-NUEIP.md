# 競品分析 · NUEIP（人易科技股份有限公司）

> 標的：<https://www.nueip.com/>
>
> 版本：v1.0（2026-08-05）｜分析人：ahern + Claude Code
>
> **一句話結論**：NUEIP 是台灣人資 SaaS 第一梯隊（自稱 3,500+ 企業、2015 成立、2023 獲 VENTURE+ A 輪），**而且它十年前就在講「首創 LINE 打卡、免安裝 APP」**——LINE 當員工端這個位置**已經被它佔住**。它甚至有真的機器學習（離職風險預測用 XGBoost，宣稱 70% 準確率）。我方**不能**再用「不用裝 App」當差異化，那是它的既有文案。真正的分野是：**它的 AI 全部作用在已結構化的 HR 資料上，沒有任何非結構化對話理解能力**——「對話 → 工作記錄」這一層在它產品裡完全不存在。它的客戶名單同時涵蓋**製造與醫療照護**，正是我方射程，所以更該把它當**整合對象而非正面對手**。

【推】舊部落格稱「每月 790 元、人數不限」應為早年舊方案，與雲市集價衝突，現已改人數計價。

【官】**無免費方案，只有 30 天試用**。

## 4. LINE 整合 —— 做得很深，是它的核心賣點

- 【官】LINE／WeChat 打卡、請假、簽核、即時推播；**帳號綁定 LINE 個人帳號防代打卡**；介面語言隨系統切換
- 【三】2023 募資稿：**「使用 LINE 整合服務的人數超過 18 萬人次」**

【推】**「LINE 當員工端」這個位置 NUEIP 已經佔住了。** 但它的 LINE 是**表單型互動**（點按鈕打卡／送單），本質仍是「員工主動操作結構化流程」。我方是**被動監聽自然對話再抽取**，零操作。

> **差異在「操作 vs 不操作」，不在「LINE vs App」。這條敘事必須重寫。**

## 8. 與 ai-center-line 的重疊分析

| 面向 | NUEIP | ai-center-line |
|---|---|---|
| 員工端安裝 | 零 APP（LINE 綁定） | 零 APP（LINE 群組） |
| 員工端動作 | **點選單打卡／填表單請假** | **零動作** |
| AI 作用對象 | 已結構化的 HR 資料 | **非結構化對話** |
| 產出 | 出勤／薪資／排班／離職風險 | 日報／任務／工單 |
| 客群 | 中小企業（含製造、長照） | 中小製造、長照 |
| 定價 | 不公開（雲市集 ~NT$136.5／人／月） | 未定 |
| 開放性 | **有開放 API 與 JSON 串接** | — |

### 態勢判讀【推】

1. **HR + 出勤這塊已被吃下。** 正面打打卡／薪資／排班是自殺：它有 3,500 家、10 年、真 ML、政府雲市集通路。
2. **但它的員工端摩擦不是零，是「低摩擦的結構化操作」。** 我方的價值是**連那一次點擊都不用**——工廠師傅在群組講「今天 3 號機做完 500 片」就變日報。這是它架構上做不到的。
3. **最脆弱的敘事是「不用裝 App」**——它十年前就這麼講了。改講「不用學新流程、不用多按一下」。
4. **它有開放 API → 應視為整合對象。** 我方抽取出來的出勤／工時可以往它推，而不是自己重做一套 HR。

## 9. 對我方的行動建議

| 建議 | 理由 |
|---|---|
| **不做 HR**（薪資／排班／勞健保） | 打不贏，也不該打 |
| **主張改為「零輸入」** | 「零 APP」已被佔位十年 |
| **把 NUEIP 當整合對象** | 它有開放 API；客戶若已用 NUEIP，我方補的是它沒有的抽取層 |
| **出勤只當附加值** | 不當主打、不單獨收費 |
| **對外簡報別泛稱「HR APP 員工端很爛」** | Femas 4.64★、104 4.46★ 會當場打臉；要點名就點業務王（1.35★）與震旦雲（1.83★） |
