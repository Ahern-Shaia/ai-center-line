# aiproot 產品功能清單

> 依 **2026-08-03 實際程式碼**盤點（導覽列、後端模組、LINE 側流程），非規劃書。

## 0. 一句話

> 把工廠／機構現場的 **LINE 群組對話**，自動變成看得懂、管得動的**營運資料** —— 員工什麼都不用改。

三條主線：**① 對話進來 → ② AI 變成任務／日報 → ③ 主管在戰情室確認與追蹤**。

---

## 1. 使用者與入口

| 角色 | 主要入口 | 一句話 |
|---|---|---|
| **現場員工** | **LINE**（bot 私訊 + LIFF 網頁） | 照常用 LINE；私訊幾則就有日報 |
| **部門主管**（group_owner） | 戰情室後台 | 看自己部門的任務、日報、群組日誌 |
| **總經理室**（tenant_admin） | 戰情室後台 | 看全公司；管部門/成員/設定 |
| **助理**（assistant） | 戰情室後台 | 協助處理通知與行政設定 |
| **AIPROOT 平台**（aiproot_admin／consultant） | 平台後台 | 跨租戶營運、模型與成本、健康度 |

## 2. 員工端 · LINE 內（零學習成本）

| 功能 | 狀態 | 說明 |
|---|---|---|
| **LINE 綁定** | ✅ | 加 bot 好友 → 點按鈕走 LIFF 完成綁定，綁定後才有個人功能 |
| **私訊記工作** | ✅ | 隨手私訊 bot「9:30 科技大樓上課」→ 回「✓ 已記錄」 |
| **`日報` 指令** | ✅ | 傳「日報／看日報／我的日報」→ 回按鈕開啟今日日報 |
| **我的日報（LIFF）** | ✅ | AI 把當日私訊整理成條列；可編輯、加項、**送出給主管** |
| **立即整理** | ✅ | 不等排程，當場叫 AI 整理已收到的訊息 |
| **原始訊息可見** | ✅ | AI 還沒整理前，先看得到 bot 收到什麼（不必等） |
| **指派任務帶入日報** | ✅ | 指派給你的任務會出現在**今天**的日報，一鍵加入（不可回填舊日期） |
| **外勤打卡（LIFF）** | 🚧 | 定位打卡、標記客戶／案場；**自動出勤狀態機未做**（#32） |

| **任務完成回報** | 🚧 | 私訊回報完成 → 關聯任務；完整生命週期待 #48 |
| **群組 ID 小幫手** | ✅ | 導入用工具 bot：拉進群打「群組ID」即回傳，取得後可移除 |

## 3. 主管端 · 戰情室「營運」

| 功能 | 狀態 | 說明 |
|---|---|---|
| **任務看板** | ✅ | 待簽核／逾時警示／已簽核三欄；卡片顯示**來源群組**、分類、信度、逾時/卡住天數、當責人 |
| ├ 簽核 | ✅ | 逐張確認 AI 抽對了；可展開**對照原始對話** |
| ├ 派發 | ✅ | 指派給成員（未綁定者標「待認領」，不亂猜人） |
| ├ 只看卡住的 | ✅ | 已簽核但沒人回報／沒派工的，一鍵聚焦 |
| ├ 存查次頁 | ✅ | 公告／已完成／已忽略分流，不塞主看板 |
| **總覽儀表** | ✅ | 簽核率、群組健康度、高信心比例等 |
| **群組日誌** | ✅ | 各 LINE 群每日活動摘要；可展開原始訊息對照；分析未完成會明說（不偽裝成「沒事」） |
| **部門日報** | ✅ | 部門成員送出的個人日報；日期分組、預設隱藏未回報、可切「未回報」查誰沒交 |
| **素材** | 🚧 | 群組照片／檔案集中查看；**AI 讀圖未做**（#42） |

**資料範圍**：部門主管只看自己部門、總經理室看全公司（RLS 強制，非前端過濾）。

## 7. 產品邊界（做不到 / 目前不做）

**誠實講清楚，比事後解釋好。**

| 邊界 | 原因 |
|---|---|
| **無法抓 LINE 歷史訊息** | LINE 平台限制：bot 只能被動收「加入之後」的訊息。要分析過去對話只能用**手動匯出檔上傳** |
| **不主動推播派工給員工** | 產品裁定：AI 分派結果需人確認，避免指派給錯的人 |
| **不做金額加總／業績統計** | 金額只抄不算（R11），統計屬另一個模組（營運問答助理 #33 未做） |
| **不自動寫進員工日報** | 指派任務／打卡地點只做「建議」，由本人決定納入 —— 本人是歸屬錯誤的最後防線 |
| **未綁定者無法自動歸屬** | 導入期正常：AI 抽到人名但對不到帳號 → 標「待認領」由主管手動派 |
| **不回寫 ERP／Ragic（分析結果）** | 尚未實作，目前僅單向：Ragic → LINE 通知 |
| **暫不支援暗色模式** | 前端鎖定 `observability-light` 淺色 profile |
