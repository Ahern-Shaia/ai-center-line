權限設定手冊

設定成「總經理看全公司、各部門主管只看自己部門」。不用寫程式，照著點就好，約 10 分鐘。
給誰看：客戶公司的總經理室管理者 ｜ v1.0（2026-07-30）

先搞懂：身分決定看得到多少

畫面上的身分這是誰看得到
總經理室老闆、管理層全公司所有部門
群組負責人各部門主管只有他自己那一個部門
員工一般同仁只有他自己的日報
📌 範圍限制由系統自動處理，主管不可能點到別部門的資料 —— 設錯也不會外洩，放心。

1先把「部門」建好

主管要綁到部門，所以部門要先存在。到左邊選單 設定 → 部門 / 成員，停在上方的「部門」分頁，按「＋ 新增部門」，把業務部、技術部、售後服務部等一個個建起來。

2建立各部門主管（設成「群組負責人」）

切到「成員」分頁 →「＋ 新增成員」。填 Email、顯示名稱、初始密碼；角色選「群組負責人」，所屬部門選他負責的那個。

⚠️ 「所屬部門」一定要選。沒選的主管，系統會保守處理成「幾乎看不到東西」（不是看全部）—— 這是最常見的設定錯誤。

3把 LINE 群組分派到部門

這一步決定「哪個 LINE 群的對話，算哪個部門的任務」。到 設定 → 通訊管道 的「LINE 群組」分頁，每個群右邊的「部門」下拉選好。

維修派工群請選擇 ← 還沒選
⚠️ 沒做這步，主管的部門會是空的 —— 對話進不到他的部門。上方若顯示「N 群未分派部門」，就是還沒選完。

設錯時對照這裡

部門主管登入後什麼都看不到？

最常見是忘了選「所屬部門」。回成員分頁編輯他，把所屬部門補上。

部門主管看得到別部門的資料？

檢查他的角色是不是被設成「總經理室」了 —— 那個身分本來就看全公司。改成「群組負責人」。

一位主管同時管兩個部門？

目前一個人只能綁一個部門。要同時看兩個，只能給「總經理室」（但會看到全公司），或請 AIPROOT 評估。

主管看得到部門，但裡面沒有任何任務／日報？

兩個可能：① 步驟 3 沒做，LINE 群組還沒分派到這個部門；② 員工還沒在 LINE 上送出日報。

現在好像每個人都看得到全部？

因為多數帳號目前是「總經理室」。把該當主管的人逐一改成「群組負責人」並指定部門即可。

一頁總結

目標：總經理看全部、部門主管看自己部門 總經理 → 角色設「總經理室」（要請 AIPROOT 建） 部門主管 → 角色設「群組負責人」＋ 指定「所屬部門」 三步驟（都在「設定」選單裡）： 1. 部門/成員 → 部門分頁 → 建好所有部門 2. 部門/成員 → 成員分頁 → 建主管（群組負責人 + 所屬部門） 3. 通訊管道 → LINE 群組 → 每個群選它屬於哪個部門 最容易忘：主管的「所屬部門」一定要選，不選＝他看不到東西。
總經理（總經理室帳號）由 AIPROOT 建立；部門主管（群組負責人）總經理自己就能建。
