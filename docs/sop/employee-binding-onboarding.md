# 員工 LINE 綁定教學

> 給客戶方員工的 3 步驟綁定指引。可列印張貼、Email 附件、或群組 pinned message。
>
> 版本：v1.0（2026-07-23）｜對應：ai-center-line LIFF Zero-Config 綁定

---

## 為什麼要綁定？

綁定後 · 你可以享有：

- **個人日報自動整理**：私訊給公司 Bot 的工作內容 · AI 自動整理成日報 · 下班前一鍵送出主管
- **群組發言自動歸屬**：你在工作群發的訊息（工單、進度）· 系統會自動記到你名下
- **不改變 LINE 使用習慣**：不必登入額外網站、不必背新密碼

不綁定 · LINE 使用方式完全不變 · 但個人日報功能無法使用。

---

## 綁定步驟 · 3 步 · 全程約 1 分鐘

### 步驟 1 · 加公司 Bot 好友

用 LINE 搜尋公司 Bot 的 ID（例：`@twh-factory`）· 加為好友。

> **從哪拿到 Bot ID？**
> - 詢問公司資訊窗口
> - 或掃公司提供的 QR code
> - 或請主管在部門群 pin 公告

加好友完成後 · Bot 會**立即傳一則訊息給你**：

```
歡迎！點下方按鈕在 LINE 內完成綁定 · 全程 60 秒 · 免登入網頁
[ 開始綁定 ]
```

---

### 步驟 2 · 點「開始綁定」按鈕

點下 Bot 剛推的按鈕 · LINE 會自動在 App 內開啟一個小網頁（LIFF）· **不跳出到瀏覽器**。

畫面會顯示：

```
✨ 系統已識別你的 LINE 資料 · 請確認

姓名：王愛麗絲
（可修改）

常用群組：
✓ 福祉—品保部（85% 訊息）
  福祉—業務部（15%）
```

- **姓名** 預設是你的 LINE 顯示名 · 可以改成公司稱呼（例：「王小姐」→「王愛麗絲」）
- **常用群組** 系統從你近 30 天在群發過的訊息自動推薦 · 選你的**主要工作群**

若姓名和群組都對 · 直接跳步驟 3。若有錯 · 用畫面上的編輯調整。

---

### 步驟 3 · 送出

點「確認綁定」→ 顯示：

```
✓ 綁定成功！
你的部門：品保部
```

點右上 X 關閉小網頁 · 回到 LINE 聊天視窗。

---

## 綁定成功後 · 你可以做什麼

### A · 私訊 Bot 記工作

在你和 Bot 的私訊視窗 · 隨時傳工作內容：

```
你：早上跟 A 客戶開會 · 討論 Q3 交期
Bot：✓ 已記錄

你：下午 3 點跟人資申請 2 名檢驗
Bot：✓ 已記錄
```

Bot 只會回 `✓ 已記錄` · 不打擾。

### B · 下班前 · 進「戰情室 → 我的日報」

系統每天下午 17:30 會**自動幫你整理今日私訊成日報**：

```
今日日報 · 王愛麗絲 · 2026/7/23

1. 08:30-10:00 · A 客戶 Q3 交期討論
   結論：客戶要求提早 15 天 · 品保確認可配合
   追蹤：明日 09:00 跟人資申請 2 名檢驗

2. 15:00 · 內部人資申請
   已於群組通知 · 待人資回覆
```

檢查一下 · 有錯改一改 · 按「送出日報」→ 主管會收到 LINE 通知。

## 常見問題

### Q1 · 我加了好友 · 但沒收到綁定按鈕

- 確認你**真的加好友成功了**（不是搜尋過但沒按加入）
- 移除 Bot 好友 · 重新加一次
- 若還是沒有 · 聯繫公司資訊窗口

### Q2 · 點綁定按鈕出現「400 error」or「需要 developer 權限」

- 這是**公司端的設定問題** · 不是你的錯
- 聯繫公司資訊窗口說明「LIFF channel 尚未 Publish」

### Q3 · 綁定成功但私訊 Bot 沒反應

- 檢查你發的是不是**文字訊息**（貼圖 / 圖片目前不會回應）
- 若還是壞 · 聯繫公司資訊窗口

### Q4 · 我換手機了 · 之前的綁定還有效嗎

- **同一個 LINE 帳號** 換手機 · 綁定繼續有效（不用重綁）
- **換 LINE 帳號**（新號碼、新註冊）· 需重新加 Bot 好友 + 走綁定流程

### Q5 · 我不小心把 Bot 封鎖了 / 移除好友

- 重新加好友 · Bot 會再推綁定按鈕
- 之前的綁定記錄還在 · 點按鈕會顯示「已綁定為 XXX」

### Q6 · 我想解除綁定

- 私訊 Bot「解除綁定」（v1 未實作 · 需聯繫公司資訊窗口）
- 或聯繫 aiproot 業助後台撤銷

### Q7 · 我在群裡發的訊息會被 AI 讀嗎

- 是 · 但**只有 AI 分析** · 不會有人主動看
- 分析結果會出現在部門主管的「任務看板」（若 AI 判斷是工作項目）
- 若不想被分析 · 私訊 / 群外聊 · 不進工作群

### Q8 · 系統會不會拿我的訊息內容做別的用途

- 不會。訊息只用於：
  - AI 整理成日報（給你和主管看）
  - AI 抽取工作任務（給主管看板）
- 沒有 aiproot 業助或主管會主動翻你私訊
- 所有讀取都會留稽核紀錄

## 資安提醒

- 綁定完成後 · **不要**在私訊給 Bot 傳密碼、個資、銀行帳號等敏感資訊
- Bot 只是工作記錄工具 · 不是安全通道
- 若 Bot 主動要求你「傳送密碼」等 · **一定是釣魚攻擊** · 立即聯繫公司資訊窗口

## 給公司資訊窗口 / IT 的說明

若員工回報綁定問題 · 對應處理：

| 員工回報 | 你檢查 | 動作 |
|---|---|---|
| 加了好友沒收訊息 | Render backend log 找 `[line-webhook] follow` | 若無 log · webhook 未 connect · 對照 [`liff-setup.md`](./liff-setup.md) §9.3 |
| 400 developer role | LINE Login channel status | Publish channel · 對照 [`liff-setup.md`](./liff-setup.md) §6 |
| 綁定成功但私訊沒回 | Render backend log 找 `resolveUserByLineUserId` | 若返 null · 綁定沒建成 · 對照 [`liff-setup.md`](./liff-setup.md) §9.4 |
| 想撤銷綁定 | Aiproot 後台 → 「LINE 綁定稽核」→ 找員工 → 撤銷 | 撤銷後員工重走綁定 flow |
