# 權限設定操作指南 · 總經理與部門主管

> 給誰看：客戶公司的**總經理室**管理者。
> 做什麼：設定成「**總經理看得到全公司、各部門主管只看得到自己部門**」。
> 難度：不用寫程式，照著點就好。全程約 10 分鐘。

---

## 一、先搞懂：兩種身分看到的範圍不一樣

系統裡的人分成幾種身分，跟「看得到多少」直接綁在一起：

| 身分（畫面上顯示的名字）| 這是誰 | 他看得到 |
|---|---|---|
| **總經理室** | 老闆、管理層 | **全公司所有部門**的日報、任務、簽核 |
| **部門主管** | 各部門的主管 | **只有他自己那一個部門** |
| （員工）| 一般同仁 | 只有他自己的日報 |

> 📌 **重點一句話**：想讓某位主管「只看自己部門」，就把他設成「**部門主管**」並指定他的部門；想讓某人「看全公司」，就設成「**總經理室**」。

這個範圍限制是系統在背後自動做的，主管**不可能**點到別部門的資料，不用擔心設錯會外洩。

---

## 二、誰可以設定誰

| 你想建立的帳號 | 誰能建 |
|---|---|
| **總經理室**（看全公司）| ⚠️ 只能請 **AIPROOT（我們）** 幫忙建 |
| **部門主管** | ✅ **總經理室自己就能建**（下面教你）|

> 為什麼總經理室不能自己建總經理室？這是刻意的保護 —— 避免公司內部有人偷偷開一個「看全公司」的帳號。要開這種帳號，統一經過我們留紀錄。

---

## 三、設定三步驟

要達成「各部門主管看各部門」，只要做完三件事。**照順序做**。

### 步驟 1️⃣ · 先把「部門」建好

主管要綁到部門，所以部門要先存在。

1. 左邊選單點 **設定 → 部門 / 成員**
2. 停在上方的「**部門**」分頁
3. 右上角按「**＋ 新增部門**」
4. 填部門名稱（例：`業務部`、`技術部`、`售後服務部`）→ 按儲存
5. 每個部門都重複一次

✅ 建好後，你會在清單看到所有部門。

---

### 步驟 2️⃣ · 建立各部門的主管（設成「部門主管」）

1. 一樣在 **設定 → 部門 / 成員**，這次切到上方「**成員**」分頁
2. 右上角按「**＋ 新增成員**」
3. 表單這樣填：

   | 欄位 | 填什麼 |
   |---|---|
   | **Email** | 他的登入帳號（要是沒人用過的信箱）|
   | **顯示名稱** | 他的名字，例：`王經理` |
   | **角色** | ⚠️ 選「**部門主管**」|
   | **所屬部門** | ⚠️ 選他負責的那個部門 |
   | **初始密碼** | 先設一組（至少 6 個字），請他登入後自己改 |

4. 按「**新增成員**」

✅ 這位主管登入後，就只看得到他那個部門的東西。
🔁 每位部門主管都重複一次步驟 2。

---

### 步驟 3️⃣ · 把 LINE 群組分派到部門

這一步決定「哪個 LINE 群的對話，算是哪個部門的任務」。沒做這步，主管的部門會是**空的**。

1. 左邊選單點 **設定 → 通訊管道**
2. 停在「**LINE 群組**」分頁
3. 清單上每一個群，右邊都有一個「**部門**」下拉 → 選它屬於哪個部門
4. 上方若顯示「**N 群未分派部門**」，代表還有群沒選，把它們選完

✅ 分派完，那個群的日報和任務就會歸到對應部門，該部門主管才看得到。

---

## 四、做完後，怎麼確認有設對？

| 想確認 | 怎麼看 |
|---|---|
| 主管身分對不對 | **設定 → 部門/成員 → 成員**，看那個人的「角色」欄是不是「部門主管」、「所屬部門」有沒有填 |
| 群組有沒有分派 | **設定 → 通訊管道 → LINE 群組**，上方不該再有「未分派部門」的提醒 |
| 主管實際看到的 | 請那位主管登入，看他的「部門日報」「任務看板」是不是**只有他部門**的內容 |

## 五、常見問題（設錯時對照這裡）

**Q1｜部門主管登入後，什麼都看不到 / 是空的？**
最常見原因：**忘了選「所屬部門」**。沒有部門的主管，系統會保守處理成「幾乎看不到東西」（不是看全部）。
→ 回 **成員** 分頁，編輯那位主管，把「所屬部門」補上。

**Q2｜部門主管看得到別部門的資料？**
檢查他的角色是不是被設成「**總經理室**」了 —— 那個身分本來就看全公司。
→ 編輯他，角色改成「**部門主管**」。

**Q3｜某位主管同時管兩個部門，怎麼辦？**
目前一個人**只能綁一個部門**。若他真的要同時看兩個部門：
- 要嘛給他「總經理室」（但這樣他會看到全公司，不只那兩個部門）
- 要嘛請我們評估（跨部門但非全公司的設定目前需要另外處理）

**Q4｜主管看得到部門，但裡面沒有任何任務 / 日報？**
兩個可能：
- **步驟 3 沒做**：LINE 群組還沒分派到這個部門 → 去「通訊管道」補分派。
- **員工還沒綁定 / 沒送日報**：日報要員工在 LINE 上送出才會出現。

**Q5｜現在公司裡好像每個人都看得到全部？**
因為目前多數帳號都是「**總經理室**」。要做到分部門，需要把該當部門主管的人，逐一**改成「部門主管」並指定部門**（在成員分頁編輯即可）。

## 六、一頁總結

```
目標：總經理看全部、部門主管看自己部門

  總經理  →  角色設「總經理室」（要請 AIPROOT 建）
  部門主管 →  角色設「部門主管」＋ 指定「所屬部門」（總經理自己建）

三步驟（設定選單裡）：
  1. 部門/成員 → 部門分頁   → 建好所有部門
  2. 部門/成員 → 成員分頁   → 建主管（部門主管 + 所屬部門）
  3. 通訊管道 → LINE 群組   → 每個群選它屬於哪個部門

最容易忘：主管的「所屬部門」一定要選，不選＝他看不到東西。
```
