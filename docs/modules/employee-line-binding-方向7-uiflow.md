### E-2 · Alice 用私人 LINE 帳號綁 · 而非公司預期

系統不知這是私人還是公司帳號 · 綁定生效。若客戶介意 · 需在客戶溝通時說明清「請用你日常會用的 LINE」。

系統不做特別處理。

```
└──────────────────────────────────────────────────────────────────┘
```

Aiproot 業助管理頁看到 · click「重發密碼」重新產生。

### E-4 · Alice 換手機 · LINE UserId 變

Alice 新手機的 LINE 是同一帳號 · UserId 不變 · 綁定仍有效。
Alice 用**不同 LINE 帳號**重綁 · 系統顯 conflict：「你已綁定 Uabc... · 是否更換為新 Uxyz...？」需 aiproot 業助 approve 更換。

### E-5 · Bob 拿到 Alice email + 一次性密碼 · 冒名綁自己 LINE

- Bob 用自己 LINE 授權 · 綁到 Alice 的 aiproot user
- **Alice 收 email 通知「你已綁定」** · Alice 沒申請卻收到 · 立刻點「撤銷此綁定」
- Alice 撤銷後 · Aiproot 業助 audit 頁面看到「Alice 於 X 時撤銷 · 值得追」
- 業助聯繫 Alice · 若確認為冒名 · 停用該 aiproot 帳號 · 重新申請流程 + 通知客戶方安全事件
