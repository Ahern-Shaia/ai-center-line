## 2. 現況問題（2026-08-27 · 依實際截圖，非印象）

三個分頁品質差很多。

### 2.1 批次品質 —— **不用大改**

有 KPI 列、有敘事（「這條規則是從資料反推出來的，40 批全部吻合」）、
散佈圖＋明細表＋長條圖＋製程時序，底部還有誠實的資料涵蓋範圍註腳。
**這頁的水準可以拿去募資。** 改版時它是「其餘兩頁要對齊的基準」。

### 2.2 平面圖 —— ⛔ **最弱，而且是第一個分頁**

| # | 問題 | 嚴重度 |
|---|---|:-:|
| ① | **上半約 40% 面積是四個空框** —— 廚房 / 洗米區 / 原物料緩衝室 / 乾料米庫，裡面一個字都沒有 | ⛔ |
| ② | 鍋爐室整區空白 | ⛔ |
| ③ | 燈號是直徑約 40px 的實心圓，像紅綠燈玩具。**沒有數值、沒有 icon** —— 狀態只靠顏色，違反 §A3（WCAG 1.4.1）| ⛔ |
| ④ | ⚡ ★ 直接用 **emoji** 當工業符號 | 高 |
| ⑤ | 整個 1440×1400 的畫面，只傳達了「15 台設備、2 台不正常」| ⛔ |

> **一個廠商點開第一頁看到四個空盒子，不會翻到第三頁。**

### 2.3 巡檢 —— 密度尚可，但**視覺語言不統一**

三個分頁有**三種 KPI 卡樣式**（`.k` / `.bq-kpi` / `.in-kc`）、三種圖表風格。
那是我做巡檢時為了不動到既有版面而刻意隔離的（`in-` 前綴），
在「三頁各自獨立」的前提下是對的 —— **但改版的前提正好相反**。

## 3. 要做的事

> 順序有意義：3.1 沒做完，3.2 之後每一項都要做兩次。

### 3.1 ⭐ 先抽 design token（D2 的前置）

現況顏色全是硬編 hex，而且**同一個語意在三頁有三個值**。
抽成 CSS 變數 + 兩份主題（`:root` / `:root[data-theme="light"]`）。

```
--surface / --surface-2 / --line / --ink / --ink-2 / --ink-3
--ok / --warn / --danger / --muted / --brand
```

### 3.2 平面圖救回來

| 現況 | 改成 |
|---|---|
| 四個空框 | 填該區匯總：「蒸區 7 台 · 6 正常 · 平均 98.2°C」+ 迷你趨勢 |
| 純色大圓 | 點位卡：**機台名 + 當前數值 + 製程階段進度環 + 迷你趨勢** |
| 狀態只有顏色 | 色 **+ 形狀 + 文字**（⬤ 正常 / ▲ 注意 / ■ 告警）· §A3 |
| ⚡ ★ emoji | 正規 SVG 圖標 |
| 鍋爐室空白 | 要嘛填內容，要嘛**明講「本期未納入」**（現在是靜默空白，看起來像壞掉）|

### 3.3 三頁統一

KPI 卡、圖表軸樣式、字級階梯、間距，全部收斂成一套。
以 **2.1 批次品質** 為基準往外套。

### 3.4 巡檢分頁補互動（原本就欠的）

- hover 十字線 + 讀數氣泡（現在完全沒有 tooltip）
- x 軸加 4~5 個時間刻度（現在只有頭尾，看得出斷線卻說不出斷在何時）
- 游標停在斷點時明說「此時段無回報」

> ⚠️ **不引圖表套件。** 理由不是省體積（Chart.js 內嵌約 200KB，頁面 71KB → 270KB 仍可接受），
> 是三個：①這頁必須能 `file://` 雙擊開，業務去客戶端不一定有網路；
> ②頁面既有三張圖全是手寫 SVG，再進一套等於同頁兩種畫圖方式；
> ③**套件預設樣式跟本頁主題不合，省下的時間會全部還回去**，而且容易調成「看得出是黏上去的」。
>
> 而且本頁最需要講的兩件事 —— 「空桶是沒回報不是零」「這點是 120 個桶的中位數」——
> 套件的預設 tooltip 不會幫你講。**tooltip 文案要自己控制。**

## 4. 不要做的事

| 不做 | 為什麼 |
|---|---|
| 把巡檢資料變成即時 | 死資料（`smart-inspection.md` 檔頭①）· 改版不改變這件事，**「快照」那條橫幅不可以拿掉** |
| 跟 ai-center-line 戰情室共用元件 | 兩個是分開的產品（`smart-inspection.md` 檔頭②）· **視覺可以像，程式碼不可以連** |
| 引圖表套件 | 見 §3.4 |
| 為了好看而美化數據 | 99.3% 異常率、5 台停止回報是**事實**。改版是讓事實更好讀，不是蓋掉 |
