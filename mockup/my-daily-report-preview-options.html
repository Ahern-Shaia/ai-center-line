各方案取捨
A · 即時預覽在下方
優點
  • 所見即所得 · 一改就變
  • 不需切換 · 認知負擔最低
  • LIFF 手機頁面會變很長
缺點
  • LIFF 直排 · 手機用戶要下滑才看到
  • 編輯 + 預覽同頁 · 資訊密度高
B · Dialog 內預覽
優點
  • 編輯頁最乾淨
  • 送出前強制看一次 · 不易誤送
  • 手機 dialog 直接聚焦
缺點
  • 編輯過程看不到「主管將看到」的樣子
  • 發現要改要關 dialog 回編輯
C · Tab 切換
優點
  • 手機空間最省 · 一次一 view
  • 使用者主動切預覽 · 意圖明確
缺點
  • 要點 tab 才看到 · 有些人不會切
  • 編輯時看不到成果
